Uninstall Instructions

Windows

To uninstall the Emps-World application, go to Control Panel > Programs > Uninstall a program, select Emps-World, and click Uninstall. This will remove the application and all related game files from your system.

MacOS & Linux

To fully uninstall Emps-World, follow these two steps:

  1. Remove the application bundle:

    • MacOS: Drag the Emps-World app from the /Applications folder to the Trash.

    • Linux: Remove the application using your package manager or delete the installed files manually, depending on how you installed it.

  2. Delete the user cache folder:
    Open a terminal and run the following command:
    rm -rf ~/.emps_world
