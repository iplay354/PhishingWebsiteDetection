TAPAS Technical Overhaul 2025

The TAPAS technical development team at Northeastern University has been working for several years on a major overhaul of TAPAS, with an emphasis on security, accessibility, and improving the user experience. The site’s current Drupal-based platform reached its end of life as of January 2025. It was not possible to complete the overhaul by then, so TAPAS is currently offline for a period of time in early 2025. We are working hard to ensure that this downtime is as brief as possible, but it will be a few months. If you have plans to use TAPAS in 2025, please contact us at info@tapasproject.org so that we can keep you posted about the schedule and let you know what will be possible. As we prepare for the relaunch and migration to the new site, we will also be reviewing the existing TAPAS data and removing draft and test materials. We will make contact with their owners before deleting anything. If you have any questions or concerns, please email us!

As part of this overhaul, we will:

  • streamline the user interface and all of the TAPAS workflows
  • improve accessibility and security
  • implement responsive design and support for mobile usage
  • expand the set of view packages
  • make it easier for TAPAS to work with outside contributors on developing new view packages

Finally, we will also be planning some beta-testing of the new TAPAS prior to the relaunch. If you’re interested in participating, please reach out to us at info@tapasproject.org!

Road map and progress report

Here are the steps that lie ahead in the overhaul; we’ll update this list as we make progress!

  • Done—Upgrade our XML database backend to ensure future maintainability
  • Done—Upgrade our version of Rails to ensure future maintainability
  • Expand Rails application to include user management and webpage display
  • Refresh the styling of TAPAS webpages and view packages
  • Purge obsolete users and data, after consulting with project owners
  • Migrate users and data into the new system
  • Engage in beta testing and bug fixes

We plan to update this page with our progress, so please check back regularly!
