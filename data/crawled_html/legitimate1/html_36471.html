JSDAI

JSDAI™ is an Application Programming Interface (API) for reading, writing and runtime manipulation of object oriented data defined by an EXPRESS based data model. Such models are widely used in STEP (ISO 10303), PLIB (ISO 13584) and other ISO, IEC and DIN standards.

[read more about JSDAI]

JSDAI is available as free software, released under AGPL v3.

[read more about JSDAI license]

Since version 4.0.0, JSDAI is available for Eclipse platform as a plugin, creating a powerful and convenient IDE. Download JSDAI plugins for Eclipse as well as JSDAI source code from the Download page.

[download JSDAI]
