The Adventist Organizational Directory provides an organizational locator and standard reference for Adventist organizations and entities worldwide. This database differs from the Adventist Yearbook in that the Yearbook does not contain local churches and schools and information in the Yearbook is updated only once a year. (Only basic contact information can be updated via the Directory for Yearbook entries. Other changes must go through the normal Yearbook process).

Churches and schools are available for North America and some Non-NAD divisions. (Information for Non-NAD churches may be out of date or inconsistent). Please submit any change requests via the "request change" links provided below each entry. (This directory does NOT currently contain information about conference or institutional employees. Please contact the local conference/union/division for this information.)
