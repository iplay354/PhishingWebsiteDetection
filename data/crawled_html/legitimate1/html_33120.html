Projects

Debian

I'm a DD, so you will find my packages in Debian and in derived distributions (i.e. in Ubuntu).

The section Debian describe the packages I maintains and some developer informations about my packaging procedures.

Linux (kernel)

I'm a long term reader of lkml.org. I'm interested in configuration and building procedures.

In kernel, I created tools to create a database which link hardware to kernel configuration: the Linux Kernel Driver DataBase, and a prototype of kernel autoconfiguration: the autokernconf.

Tools

I created a powerfull sitemap.xml generator: gen-sitemap, to help generating and handling sitemaps. Sitemaps are file used by searching engines, to optimize (relative priorities and frequencies) the scanning of a site.
