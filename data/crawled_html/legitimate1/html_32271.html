Data Masking

Data masking is a special way of encrypting and displaying sensitive data. Unauthorized users or applications see data in masked form. For example "****-****-****-9363" or "0000 0000 0000 0000" for credit cards. Authorized users or applications see the data transparently in its original form.

Schema Protection

DbDefence's schema protection provides protection from local DBA. Database structure will be completely hidden.

Popular questions

My SQL Server and IIS located on different computers. How many licenses do I need?

You need only one single license for SQL Server. Number of database clients doesn't matter.

Does an SQL Server run slower with DbDefence?

Any time data is encrypted; it will take a little longer to decipher that data by the server. However, you should not experience any significant reduction in the loading time of your data. Our software is currently highly opimized and we are constantly working on ways to improve it. The real question is, can you really afford to not have your data encrypted?

If I backup an encrypted database can I restore it on another server?

Yes, but when you restore the encrypted database, it will remain encrypted. You cannot remove the encryption by following the backup and restore procedure. Backup files are encrypted by default.
