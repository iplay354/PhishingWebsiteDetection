Data Services

Data

NSF Unidata helps researchers and educators acquire and use Earth Systems Science data in near real time. We support access to a wide variety of data including output from numerical prediction models, satellite observations, ground-based and airborne observation platforms.

Satellite Data

Data are available from a wide range of satellite-based observing platforms.

Gridded Data

Gridded data products from a selection of North American and European numerical weather prediction models are available.

Radar Data

Level II and Level III NEXRAD Data and U.S. National radar mosaics are available.

Learn more about NSF Unidata's data services

Open Source Software

Software Tools

NSF Unidata provides a rich set of Open Source software tools to access and visualize Earth Systems Science data, facilitating accessibility and multidisciplinary integration.

NetCDF

NetCDF is a set of software libraries, data formats, and tools that support the creation, access, and sharing of array-oriented scientific data.

MetPy

MetPy is a collection of tools in Python for reading, visualizing, and performing calculations with weather data.

AWIPS Forecasting Software

AWIPS is a meteorological display and analysis package used by the National Weather Service.

Learn more about NSF Unidata's software offerings
