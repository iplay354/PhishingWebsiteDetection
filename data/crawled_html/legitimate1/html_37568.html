What m-Power is (and isn't)

Low-code is a broad term, and not all tools live up to the hype. Features, flexibility, and development models vary widely, which leads to confusion (and disappointment). If you’ve used other low-code platforms, m-Power will feel different. Here's why:

m-Power is...


  • A powerful development tool that builds enterprise-class applications
  • Fully customizable down to the code level when needed
  • A tool that uses standard languages and frameworks
  • Built on open architecture with no vendor lock-in
  • Designed for both IT teams and power users

m-Power isn't...


  • A lightweight builder for simple apps or MVPs
  • A rigid, one-size-fits-all platform
  • A tool that uses proprietary languages
  • A closed ecosystem that’s hard to leave
  • Limited to basic business users

Frequently Asked Questions

Got a question? We have answers. Have a question that you don't see here? Shoot us a note and we'll be happy to answer it! Here are a few common questions we hear about m-Power.

Aren't all low-code platforms pretty much the same?
Not at all. With its unique interface, customizability, deployment freedom, and development approach, m-Power is different than any other low-code platform you'll run across. You can deploy it anywhere, customize however you want, and never worry about user fees or limits.

It's built to fit into your current technology and work the way you work. It’s unlike other low-code tools out there, and that’s on purpose.
Which databases and servers does m-Power support?
m-Power natively integrates with any JDBC-compatible database (Db2, Oracle, SQL Server, MySQL, etc.) and can deploy to Windows, Linux, or AIX servers.
How much coding is required to use m-Power?
m-Power’s drag-and-drop interface and built-in templates let you build most applications with no coding at all. But, the option to edit at the code level or inject custom code is there if you need it.
Where can I deploy m-Power?
You can deploy m-Power on-premise, in the cloud, or a combination of the two. It's built to work over your existing database tables...wherever they are.
What types of applications can I build with m-Power?
Short answer: Anything you need. Long answer: While m-Power builds any type of custom application, customers commonly use it for reporting, database front-ends, portals, dashboards, CRM systems, budgeting applications, and much more. It's designed to let you create any type of custom business application you need.
Can I integrate m-Power with external systems and APIs?
Yes, m-Power is designed to fit into your existing systems and workflow. It can consume and expose REST services, connect to JSON endpoints, and work directly over your existing database tables.
What licensing options does m-Power have?
While we offer a yearly subscription option, most customers opt for m-Power's perpetual license. With a perpetual license, you own the software forever! That means you get unlimited data, users, applications, etc... The longer you use m-Power, the more economical it becomes.
