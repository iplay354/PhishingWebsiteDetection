Horario de tarifario

Este servicio estará sujeto al tarifario vigente y atenderá en el horario siguiente:

1. Las transferencias recibidas hasta las 12:15 horas (de lunes a viernes, excepto feriados) serán procesadas por el banco de destino entre las 13:30 y 14:00 horas del mismo día.

2. Las transferencias recibidas entre las 12:15 horas Y las 14:30 horas (de lunes a viernes, excepto feriados) serán procesadas por el banco de destino entre las 16:00 y 17:00 horas del mismo día.

3. Las transferencias recibidas entre las 14:30 horas Y las 18:00 horas (de lunes a viernes, excepto feriados) serán procesadas por el banco de destino entre las 9:30 y 10:00 horas del siguiente día útil (de lunes a viernes, excepto feriados).

4. Las transferencias recibidas después de las las 18:00 horas (de lunes a viernes, excepto feriados) serán enviadas al banco de destino al siguiente día útil y serán procesadas entre las 13:30 y 14:00 horas de dicho día.
